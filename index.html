Features Desk

What Markdown to X Articles converts

The point is not just pasting. It is reducing publishing risk around X editor changes, local images, tables, and cover handling.

01

Auto-uploads images

External URLs are fetched + uploaded via X's own media pipeline. Local images work with directory access.

02

Title & cover auto-detected

First H1 becomes the article title, first image becomes the cover. Override explicitly via frontmatter title: / cover:.

03

Tables → images

X doesn't support tables? We render to PNG and embed inline at HiDPI quality.

04

Code blocks

Fenced code with language tag → X native code block (mono, gray bg).

05

Tweet embeds

Tweet URLs are auto-converted to embed cards, just like pasting them on x.com.

06

Drag & drop .md

Drag a .md file onto the browser — extension creates a fresh draft and fills it in.

Privacy principle: the extension has no analytics, reads no cookies, and sends no article content anywhere. Everything happens in your browser. (This website uses Google Analytics for visit statistics; see the privacy policy.)

Workflow Note

An X Article formatter that works from Markdown

Most X Article formatters are web pages: you paste Markdown in, copy rich text out, then add the images yourself. This extension works inside the X editor instead. Press Ctrl+V on x.com/compose/articles, or drop a .md file on the page, and your Markdown turns into a Twitter article draft: headings folded to X's two levels, native code blocks, tables as images or native tables, tweet links as embeds, and every image uploaded through X's own media pipeline. Nothing goes out until you click Publish. New to Articles? Start with how to post an article on X.

FAQ

How do I install and use it?
Install from the Chrome Web Store, open the X article editor, then Ctrl+V your Markdown. Or drag a .md file onto the browser to create a fresh draft.
Does X Articles support Markdown?
Not natively. Paste Markdown into the X Articles editor and images become a line of ![](url), tables collapse into pipes, and code blocks lose their formatting. This extension converts Markdown to X Articles' native format on paste: images upload through X's own media pipeline, tables render as images, and code blocks keep their monospace style.
Does it leak my X account or content?
No. The extension only runs on x.com/compose/articles/*, doesn't read your cookies or password, and uploads zero article content. See Privacy Policy.
Where do I find the license key after purchase?

Creem sends an order confirmation email (subject roughly Your X Article Markdown Paste order) to the address you entered at checkout. Click the "View Order" link inside the email to open your order page on Creem:

Once you have the key, click the extension icon in Chrome's toolbar, paste it into the License Key field, press Enter. Each key activates on up to 5 devices.
