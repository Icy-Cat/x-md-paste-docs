Features Desk

能处理什么

它解决的不是复制粘贴本身，而是 X 编辑器改版、本地图片、表格和封面带来的不确定性。

01

图片自动上传

外链图片会自动下载，并通过 X 自己的媒体通道上传。本地图片授权目录后也能直接引用。

02

标题和封面自动识别

第一个 H1 会作为文章标题，第一张图片会作为封面。也可以在 frontmatter 里用 title:、cover:（或 标题:、封面:）指定。

03

表格 → 图片

X 文章不支持表格，扩展会把表格渲染成清晰的 PNG，再自动插入正文。

04

代码块保留格式

带语言标记的代码块会转成 X 原生代码样式，保留等宽字体和灰底格式。

05

推文链接自动嵌入

正文里的 X 推文链接会自动变成嵌入卡片，效果和在 X 网页里直接粘贴一致。

06

拖入 .md 文件

不用先复制全文，直接把 .md 文件拖进浏览器，扩展会新建草稿并填入内容。

隐私原则：扩展不接入统计，不读取 cookie，也不上传文章内容。所有处理都在你的浏览器里完成。（本官网使用 Google Analytics 统计访问，详见隐私政策。）

Workflow Note

一个从 Markdown 出发的 X 长文排版工具

多数 X 长文排版工具是网页：把 Markdown 贴进去，复制富文本出来，图片再自己一张张补。这个扩展直接在 X 编辑器里工作。在 x.com/compose/articles 按 Ctrl+V，或者把 .md 文件拖到页面上，Markdown 就变成一篇 X 长文草稿：标题折叠成 X 的两级，代码块是原生代码块，表格可选图片或原生表格，推文链接变成嵌入，每张图都走 X 自己的媒体通道上传。你不点发布，什么都不会发出去。第一次写长文？先看怎么在 X 上发长文。

Reader Questions

常见问题

安装后怎么用？
先从 Chrome Web Store 安装插件，再打开 X 文章编辑器，用 Ctrl+V 粘贴 Markdown 即可。也可以把 .md 文件直接拖进浏览器，让扩展自动新建草稿。
X 长文支持 Markdown 吗？
X 长文编辑器本身不认 Markdown：直接粘贴会把图片变成一行 ![](url)、表格塌成一堆竖线、代码块丢掉灰底。这个扩展在粘贴时把 Markdown 转成 X 编辑器接受的原生格式，图片会走 X 自己的上传通道，表格渲染成图片，代码块保留等宽格式。
会读取我的 X 账号或文章内容吗？
不会。扩展只在 x.com/compose/articles/* 页面工作，不读取你的 cookie 或密码，也不会上传文章内容。详见 隐私政策。
付款后去哪找激活码？

目前支持 Chrome，以及 Edge、Brave、Arc 等基于 Chromium 的浏览器。Firefox 和 Safari 会放在后续版本规划里。
