在 AI 助手里把 Markdown 发到 X 长文

适用于插件 1.4.0 及以上 · 2026 年 9 月

装上 x-md-paste skill 后，你可以在 Claude Code、Codex 等 AI 助手里直接说「把这篇发到 X 长文」。它会在本机临时把这篇 Markdown 和里面的图片提供给浏览器里的 X 长文 Markdown 导入器，由插件新建草稿、渲染格式、上传图片。结果是一篇草稿，发不发由你在 X 上决定。

准备

  • 浏览器插件 1.4.0 或更新版本，从 Chrome 应用商店或 Edge 扩展商店安装，并在这个浏览器里登录 x.com。
  • Node.js 20 或更新版本。skill 附带的脚本只用 Node 自带模块，不需要 npm 安装任何东西。
  • 一个能读 skill 的 AI 助手，比如 Claude Code。

安装方式一：让 AI 助手自己装（推荐）

把下面这段话发给你的 AI 助手。不分操作系统，也不限于某一个 AI 工具。插件弹窗里的「复制安装提示词」按钮复制的就是这段。

请帮我安装「x-md-paste」skill，用来把本地 Markdown 发成 X 长文草稿：
1. 下载这两个文件：
   https://xmdpaste.icy-cat.com/skill/SKILL.md
   https://xmdpaste.icy-cat.com/skill/xmdpaste.mjs
2. 放进你的 skills 目录下名为 x-md-paste 的文件夹（Claude Code 是 ~/.claude/skills/x-md-paste/，其他工具用它自己的 skills 目录），文件名保持不变。
3. 检查本机有 Node.js 20 或更新版本，没有就告诉我。
4. 读一遍 SKILL.md。以后我说「把这篇发到 X 长文」时按它执行。
前提：浏览器里装了 X Article Markdown Paste 插件 1.4.0 以上，并已登录 x.com。安装说明：https://xmdpaste.icy-cat.com/zh/skill.html

安装方式二：一条命令

macOS / Linux，在终端里运行：

curl -fsSL https://xmdpaste.icy-cat.com/skill.sh | sh

Windows，在 PowerShell 里运行：

irm https://xmdpaste.icy-cat.com/skill.ps1 | iex

两条命令都只会往 ~/.claude/skills/x-md-paste/（Windows 是 %USERPROFILE%\.claude\skills\x-md-paste\）写入两个文件，不碰别的地方。运行前可以先打开 skill.sh 或 skill.ps1 看一眼内容。

安装方式三：手动

下载 SKILL.md 和 xmdpaste.mjs，放进 skills 目录下的 x-md-paste 文件夹，文件名不变。

怎么用

在 AI 助手里打开或提到一个 .md 文件，说「把这篇发到 X 长文」。接下来：

  1. 脚本找到装了插件的浏览器，在里面打开 X 长文编辑器。
  2. 插件取走文档，新建草稿，渲染标题、列表、代码块、表格和推文嵌入，上传图片。
  3. 文章里有图片时会弹出封面选择框，选一张或点「不设置封面」。
  4. 检查草稿，满意后在 X 上发布。

Obsidian 笔记会自动以 vault 根目录为准，![[附件/图.png]] 这类写法也能找到图片。相对路径、绝对路径、Windows 路径都支持，但图片必须在这个根目录之内。

装了多个浏览器怎么办

脚本会检查 Chrome、Edge、Brave、Arc、Chromium、Vivaldi 各个 profile 里的插件，优先用默认浏览器里版本够新的那份。想指定时，让 AI 助手在命令后面加上 --browser edge 或 --profile "Profile 2"。文档只交付一次，所以不会在两个浏览器里各建一篇。

常见问题

  • 命令说「nobody picked the document up」并退出：浏览器里没有可用的插件。它会列出找到的每一份插件和原因，常见的是版本低于 1.4.0、插件被停用、装在另一个 profile，或者没登录 x.com。
  • X 页面提示「already picked up」：同一个链接被打开了第二次。重新让 AI 助手执行一次即可。
  • 提示「the local tool is not running any more」：脚本已经空闲退出，通常是打开了一个旧链接。重新执行一次。
  • 提示部分图片上传失败：图片不在根目录内、文件不存在，或者超出了免费版每次的图片数量。
  • X 页面一直空白：X 自己的页面没加载出来，刷新 x.com 后重新执行。

更新与卸载

更新：重新运行一次安装命令或安装提示词，会覆盖那两个文件。卸载：删除 x-md-paste 文件夹。
