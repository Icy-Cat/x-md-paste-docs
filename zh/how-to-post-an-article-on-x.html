如何在 X 上发长文

2026 年 9 月更新 · 发布资格以 X 帮助中心为准

X 上的长文形式叫 Articles（X 长文）。和普通推文不同，长文有标题、封面、小标题、正文插图，没有字数限制，发出去后在你的主页和时间线里以卡片形式出现。这一页按顺序讲怎么在 X 上写一篇长文并发布，最后讲如果你本来就用 Markdown 写作，有什么更快的办法。

谁能在 X 上发长文

任何人都能看长文，但不是谁都能写。按 X 帮助中心的说法，发布长文限于 Premium 和 Premium+ 订阅用户、Premium Business 和 Premium Organizations。个人订阅用户要等账号审核通过、蓝标生效后才能用。Basic 档不在其中。

这个范围是 2026 年 1 月放宽的，之前只有 Premium+ 和机构能用。X 会不时调整规则，如果编辑器打不开，先去看上面那页帮助中心，别急着以为是哪里坏了。

第 1 步：打开长文编辑器

编辑器地址是 x.com/compose/articles。这个页面列出你的草稿和已发布的长文，有按钮新建一篇。每篇草稿有自己的编辑页，发布或删除之前一直保存在这里，关掉标签页以后还能接着写。

用电脑上的浏览器。编辑器是为桌面网页做的，粘贴和传图也都是在电脑上最方便。

第 2 步：填标题，写正文

标题是顶部单独的一栏，不属于正文。别太长，要能在时间线卡片里读完。下面的正文像一个简单的文字处理器：加粗、斜体、删除线、链接、有序和无序列表、引用。

按写博客的方式写：段落短，一段一个意思。一整堵文字墙在手机上比在显示器上难读得多。

第 3 步：用小标题分层

正文里只有两级标题：标题和副标题。主要章节用标题，副标题少用。如果草稿来自层级更多的地方（比如 Markdown 的 H1 到 H6），得压成两级。

第 4 步：插图、嵌入和封面

  • 正文插图：插在文字里对应的位置。X 每篇长文最多 25 张图。
  • 推文、视频和 GIF：长文也能嵌入这些，引用一条推文或放一段演示时有用。
  • 封面图：在标题上方的封面区域设置。它是别人在时间线卡片里第一眼看到的东西，挑一张宽图，主体放在中间，因为卡片会裁掉边缘。

编辑器没有表格按钮，通常的做法是把表格截图当图片插进去。代码的支持也有限，代码块、表格和分隔线这一页讲得更细。

第 5 步：检查，然后发布

从头到尾再读一遍，最好把窗口拉窄了读。确认图片在该在的位置、链接能点、封面裁得好看。然后点 Publish（发布）。长文会有自己的链接并出现在你的主页上，同时会有一条带长文卡片的推文推给你的关注者。

发出去以后，大家互动的对象就是这张卡片。想看它是在涨还是停了，X Viral Monitor 会在时间线里显示每条推文每小时的浏览量。

更快的办法：用 Markdown 写，一次粘贴

短文直接在 X 编辑器里写没问题。长一点的，多数人会在 Obsidian、Notion、Typora 或 VS Code 里写，麻烦就从这里开始：把 Markdown 粘进 X，得到的是原样的 ##、一行行 ![](…) 而不是图片，表格塌成一堆竖线。手动把格式补回来，比写的时间还长。

X 长文 Markdown 导入器是一个在粘贴时完成转换的 Chrome 扩展。流程变成：

  1. 在你习惯的编辑器里用 Markdown 写好文章。
  2. 打开 x.com/compose/articles，新建一篇草稿。
  3. 复制 Markdown，在编辑器里按 Ctrl+V。也可以点编辑器工具栏里的导入 Markdown选一个 .md 文件，或者直接把文件拖进浏览器窗口。
  4. 检查草稿，照常发布。

它替你处理的事：

  • 第一个 H1 作为长文标题，各级标题折叠成 X 的两级。
  • 网络图片会被下载，再走 X 自己的媒体上传。./img/chart.png 这类相对路径，从你选过一次的本地文件夹里找。
  • 封面可以用第一张图、frontmatter 里的 cover:、临时拖进来的一张本地图，也可以不设。
  • 带围栏的代码块变成 X 原生代码块；表格可以选渲染成图片或转成 X 原生表格。
  • 单独一行的推文链接变成嵌入卡片。

它不会自动发布。你最后得到的总是一篇普通的 X 草稿，检查完再自己点发布。

免费版包含全部文字格式、代码块和分隔线，每次粘贴最多 3 张图、1 张表格、1 条推文嵌入，文末有一行可以删掉的签名。新安装送 14 天 Pro 试用，试用期内没有数量限制。当前方案见价格。

从 Chrome 应用商店安装

发布前清单

  • 账号是 Premium、Premium+、Premium Business 或 Premium Organizations，蓝标已生效。
  • 在电脑上从 x.com/compose/articles 新建草稿。
  • 有标题，正文最多两级小标题，段落短。
  • 图片放好，不超过 25 张，封面经得起裁切。
  • 通读一遍，再点发布。
