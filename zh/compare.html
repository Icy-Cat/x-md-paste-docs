xPoster、MD2X 与 X 长文 Markdown 导入器对比

事实核对于 2026 年 9 月。有过期的地方请告诉我，我会改。

搜「怎么把 Markdown 发到 X 长文」会碰到这三个工具。它们路线不同，该选哪个取决于你要不要工具替你传图，以及你在不在乎它下个月还能不能用。这页是第三个工具的作者写的，看取舍时请把这点算进去。

xPoster

开源，MIT 协议，Chrome 商店约 670 个用户，GitHub 166 星。它打开一个侧边栏，你在里面粘 Markdown 或排队多个 .md 文件，它检查 X 编辑器可达后替你写草稿。论功能，它和本扩展最接近，图片和表格都能处理。

问题在维护。仓库最后一次提交是 2026 年 6 月，唯一的 open issue 是作者自己的机器人开的。整个夏天 X 改了几次长文编辑器，已有用户反馈导入跑不完。对一个往编辑器里注入的工具来说，三个月没更新，基本等于今天已经坏了。如果你愿意自己 fork 修，它是个不错的起点。

MD2X

免费网页应用，不用安装。在它的编辑器里写或粘 Markdown，它渲染成富文本复制到剪贴板，你再粘进 X。另有拆线程、Mermaid 转 PNG、代码转图片，中文界面，PWA 可离线，内容不上传服务器。

限制是结构性的：网页没法把文件上传进你的 X 草稿。远程图片工具不替你传，本地图片事后手动加，推文链接留成普通链接。代码块转成图片才能挺过粘贴，代价是读者复制不了代码。文字为主、一两张图的文章够用；十五张截图的文章就是十五次手动上传。

X 长文 Markdown 导入器

这个扩展只在 x.com/compose/articles 上运行。从任何写作工具复制 Markdown，在 X 编辑器里按 Ctrl+V。它把内容转成编辑器自己的块格式，每张图走 X 正常的媒体上传路径，表格渲染成图片，代码块保持 X 原生代码块，推文链接变成嵌入卡片。也可以把 .md 文件拖到页面上直接新建草稿，或从 Obsidian、VS Code、命令行触发。

免费版够大多数文章用：文字排版、代码块、分隔线不限，每次粘贴最多 3 张图、1 张表格，文末带一行签名。Pro 去掉限制和签名。Pro 真正买的是价格卡上那一行「X 改编辑器后的兼容维护」：仅 2026 年 9 月就发了六个修复，这是住在别人编辑器里的成本。

该选哪个

  • 纯文字文章，不能装扩展：MD2X。
  • 想读和改代码：xPoster，先做好修它的准备。
  • 文章带图、表格或嵌入，且一个月发不止一篇：X 长文 Markdown 导入器。
