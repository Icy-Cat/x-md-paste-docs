X 长文里怎么放代码块、表格和分隔线

2026 年 9 月更新 · 按当前 X 长文编辑器实测

X 长文（X Articles）是 X Premium 自带的长文编辑器。它支持标题、加粗、斜体、链接、列表、引用和图片，没有表格按钮，代码块和分隔线只有在内容以编辑器认得的形态进来时才会生效。如果你用 Markdown 写作，这一页讲清楚默认会发生什么，以及三种拿到正确排版的办法。

把 Markdown 直接粘进 X 长文会怎样

把 Markdown 纯文本粘进编辑器，得到的就是纯文本，什么都不会被解释：

  • ```js … ``` 围栏原样留成反引号，落在普通段落里，灰底等宽的代码框不会出现。
  • | a | b | 表格塌成一行竖线和横线。
  • --- 就是三个连字符，不是分隔线。
  • ![alt](https://…/image.png) 留成文字，图片不会被取回。

Google 在这个话题的「其他人还问了」里有一条「X 支持 Markdown 吗」，老实的回答是：粘贴时不支持。编辑器吃的是剪贴板里的富文本 HTML，Markdown 得先转换才能落地。

办法一：在编辑器里手动排

短文可行。打一行，选中，用工具栏的代码样式；空行上按「+」能插分隔线。表格没有对应功能，通常的替代是把表格截图当图片贴进去。

代价：每个代码块几分钟，表格每改一次就要重新截图。三千字的技术文一般在这一步放弃。

办法二：先把 Markdown 转成富文本，再粘

MD2X 这类网页转换器把 Markdown 渲染成 HTML 放进剪贴板，粘过去能得到标题、列表和行内代码。限制在于：

  • 代码块通常以预格式化文本进来，X 会把它压平，所以转换器一般把代码块转成图片。
  • 网页没法把图片上传进你的 X 草稿。远程图片链接留成链接，本地图片事后要一张张拖。
  • 推文链接留成普通链接，不会变成嵌入卡片。

办法三：用一个和编辑器对话的 Chrome 扩展来粘

X 长文 Markdown 导入器运行在 x.com/compose/articles 上，接管 Ctrl+V。它不把原始文本交给编辑器，而是按 X 内部使用的块结构把内容组装好，需要媒体的地方走编辑器自己的图片上传通道。实际效果：

  • 代码块带语言标记的会变成 X 原生代码块：等宽、灰底、缩进保留。
  • 表格渲染成高清 PNG，插在原位。X 没有表格元素，列对齐和表头会保留。
  • 分隔线（---）变成真正的水平线。
  • 图片远程链接会被取回并通过 X 的媒体通道上传；本地路径从你授权过一次的文件夹解析。
  • 推文链接单独成行的会变成嵌入卡片。

流程就三步：在 Obsidian、Notion、Typora 或 VS Code 里写，全选复制，到 X 编辑器里按 Ctrl+V。进度条显示上传进度，草稿仍是普通的 X 草稿，发布前可以继续编辑。

已知限制

  • X 每篇文章最多 25 张图，一张表格算一张图。表格很多的长文会撞到这个上限。
  • X 的代码块没有语法高亮，只有等宽和灰底，没有颜色。
  • 嵌套表格和合并单元格按原样渲染进图片，X 不会让它们可交互。
  • X 改编辑器内部结构时，扩展可能失效一两天，修复随普通 Chrome 更新推送。
